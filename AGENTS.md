# volo-flutter-ui

A Flutter design system: the `volo_flutter_ui` package (this repository's root) and its Widgetbook catalog.

| Path | Holds |
|---|---|
| `lib/` | Widgets, theme, tokens, icons. Barrel `lib/volo_flutter_ui.dart` → category barrel → `lib/src/components/<category>/v_x/{v_x.dart,v_x_style.dart}` |
| `widgetbook/` | The catalog for people to browse (`lib/use_cases`) |
| `tool/` | Token, index and doc generators (`gen_tokens.dart`, `agent_index.dart`, `component_docs.dart`) |
| `bin/` | Commands shipped to products (`agent_index.dart`, `raw_widgets.dart`) |
| `doc/` | Generated index and per-widget docs (shipped with the package) |
| `example/` | A minimal app that uses the package (outside the pub workspace) |

## Commands

- `make check` — the gate. Checks formatting, tokens, index, docs, raw widgets, analysis and tests. The `pre-push` hook (lefthook, installed by `make setup`) runs it; there is no test CI, and GitHub Actions only publish and deploy.
- `make index` — rewrites the index block below, `doc/index.txt` and `doc/**/*.md`.
- `make tokens` — rewrites `lib/src/theme/*.generated.dart` from the token JSON.

## Rules

- A widget is `v_x/v_x.dart` + `v_x/v_x_style.dart`, and its test lives in `test/components/<category>/v_x_test.dart`.
- Every public declaration needs a `///` first sentence. The index and docs are built from it, and without it `make check` fails with `file:line name`. The first sentence of the first paragraph becomes the one-line index entry, so keep it to 90 characters including the period and put details in the second sentence (longer fails with `file:line name (N chars)`; an index block must stay under 8,000 characters).
- An index line is `<file>|<main declaration>: <first sentence>` and is grouped under a `[category]` line. The doc is `doc/<category>/<file>.md`.
- Never edit `*.generated.dart` or `doc/` by hand. Produce them with `make tokens` and `make index`.
- `volo_flutter_ui` uses only the Flutter widgets layer (`package:flutter/widgets.dart`) and never imports `material.dart` or `cupertino.dart`. `make check` measures this in `lib`.
- Wrap widget tests in `VTheme` (`VTheme(data: VThemeData.light(), child: Directionality(...))`).
- When you add a widget that replaces a raw Material widget, add a line to `rawWidgets` in `lib/src/tooling/raw_widgets.dart`.
- Names follow Material conventions.
  - Disabling is `enabled` (default true). A value callback is `onChanged: ValueChanged<T>`, anything else is `onXChanged`.
  - Pressing is `onPressed` for buttons and `onTap` for tiles and chips.
  - A content slot is a `String` if it takes only text and a `Widget` if it takes anything (never `Object`).
  - An on/off value is `value`.
  - Write callback types as `ValueChanged`, `VoidCallback` or a named typedef; do not leave a bare `void Function(...)` field.
  - Each widget may have its own size enum, but its values use only the `VSize` step names (`xs` `sm` `md` `lg` `xl`) with the same ordering. Leave no `@Deprecated` aliases.

## volo_flutter_ui index

Each entry's doc is `doc/<section>/<name>.md` (`[.]` is the doc folder itself). Other public classes, enums, styles and data classes in each folder are listed in its doc file.
